# Установка MGU Yandex Navigation 0.2.1 через GitHub и MGU Store

Этот каталог `SOURCE` — **корень репозитория GitHub**: в нём уже лежит `mgu-repo.json` и открытый исходный код. Публиковать нужно именно содержимое SOURCE, а не ZIP целиком и не подпапку SOURCE.

1. Создайте пустой **Public** репозиторий, например `mgu-yandex-navigation`, в своей учётной записи GitHub. Не добавляйте при создании README/LICENSE/.gitignore: они уже есть в проекте.
2. Загрузите туда *содержимое* папки `SOURCE` (удобнее с Mac через `git`; см. `publish_from_mac.sh`).
3. После загрузки проверьте, что файл `mgu-repo.json` находится прямо в корне GitHub репозитория и открывается через браузер.
4. В MGU Store автомобиля откройте Sources → Add source → GitHub, укажите `<ваш логин>/mgu-yandex-navigation`, выберите **Branch (main)**, а не Releases. Если источники добавляются через телефон, запустите Phone page в Store, отсканируйте QR-код подключённым к автомобильному hotspot телефоном, добавьте тот же источник, выбрав branch/main.
5. Store должен показать `MGU Yandex Navigation · Experimental`. Для установки потребуется `mgu-python`, `mgu-deploy` и `mgu-uplink`, предоставляемые экосистемой Store. Установка из ветки собирает OAP на самой MGU из открытого исходного кода; от сборки через USB каталога она отличается.
6. Устанавливайте только на стоянке, без прерывания питания. Для первого запуска ключей Яндекса не требуется. Затем проверьте настройку ключа Static API и GPS.

**Статус:** публикация в GitHub подготовлена, но испытания на конкретном автомобиле ещё не выполнены. Не выкладывайте ключи API в GitHub и не присылайте их в переписку. Проверяйте действующие условия доступа Яндекса для автомобильного приложения.
