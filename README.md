# MGU Yandex Navigation 0.2.1

Самостоятельное экспериментальное приложение для BMW iDrive 7 / MGU. Целевой автомобиль — BMW X6 G06 2021; заявленная владельцем прошивка I_21w12.2-1-4 / 03/2021.50. CarPlay не используется.

**Результат: собран пакет `aren_yandex@0.2.1.tgz` и USB-каталог для MGU Store. Установка и запуск на автомобиле ещё не выполнены.** Это приложение сообщества, а не официальный клиент Яндекса или BMW.

## Установка готового пакета

1. Распакуйте поставочный ZIP на MacBook.
2. Скопируйте папку `mgu-repo` из папки `USB` в корень флешки, которую BMW уже распознаёт. Путь должен получиться `mgu-repo/mgu-yandex-navigation/catalog.json`. Сам ZIP или один `catalog.json` на флешке недостаточны.
3. Подключите флешку к BMW, откройте MGU Store → **USB**. В варианте Store со списками источник появится в **Sources / Источники**. Открытие Store запрашивает обновление списка.
4. Выберите **MGU Yandex Navigation · Experimental**, версия **0.2.1**, и **Install / Установить**. Пакет предназначен только для ID7. В каталоге заявлены `mgu-deploy >= 0.8.27` и `mgu-uplink >= 0.7.13`; при сообщении о недостающих компонентах сначала обновите их через Store.
5. Дождитесь результата установки. Затем откройте приложение в списке приложений BMW. Первую проверку выполняйте на стоящем автомобиле.
6. В меню приложения введите свои ключи API Яндекса. Для карты нужен **Static API**; для поиска адресов — **HTTP API Геокодера**; для построения маршрута — **API Получение деталей маршрута**. Один ключ годится для нескольких полей только если в кабинете ему действительно выдан доступ ко всем этим сервисам.

Для готового USB-пакета не нужны компиляция на MacBook, Android, CarPlay или извлечение SDK вручную. Store должен подготовить SDK из штатного приложения BMW непосредственно на MGU. Этот последний этап зависит от прошивки и ещё не проверен на целевом автомобиле.

Ключей в архиве нет. Без них приложение должно открываться, но загрузка карт и сетевой поиск работать не будут. Интернет для самого MGU обеспечивает `mgu-uplink`; телефон может быть точкой доступа, CarPlay для этого приложения не требуется. Возможность MGU выйти в интернет и TLS к Яндексу нужно проверить отдельно.

Подробности и устранение ошибок: [INSTALL_RU.md](docs/INSTALL_RU.md).

## Что реализовано

| Возможность | Состояние |
|---|---|
| Приложение OAP, четыре экрана RHMI, русский текст | Код и готовый пакет |
| Поиск адреса и выбор из пяти результатов | Реализован клиент HTTP Геокодера; проверен на тестовых ответах |
| Карта Яндекса, масштаб, дневная/ночная тема | Реализован Static API и PNG-декодер; живой ответ с ключом не получен |
| Построение автомобильного маршрута | Реализованы запрос, разбор геометрии, длина и время; проверено на тестовых ответах |
| Координаты штатного MGU | Подписка и опрос `Positioning.currentLocation`; реальный X6 не подключался |
| Следование по карте и обзор маршрута | Реализованы; требуется испытание с GPS и API |
| Работа при отсутствии GPS | Явное сообщение; ручная начальная точка и выбор координат доступны |
| Хранение и удаление API-ключей | Локальный файл приложения, права 0600; проверено на стенде |
| Распознавание пакета и USB-каталога Store | Проверено кодом настоящего MGU Store на компьютере |
| Установка, SDK BMW, контроллер iDrive, сон/пробуждение | Требуют автомобиля |

Это версия карт и планировщика маршрута. В ней **нет голосового ведения, подсказок поворотов, автоматического перестроения, офлайн-карт, вывода в приборную панель или HUD**. Отображаемое время — значение при запросе маршрута, а остаток пути — приблизительный расчёт по его линии. Цветной слой пробок не реализован.

Карты загружаются отдельными изображениями 650 × 260 и отображаются в области 1300 × 520. По умолчанию между запросами не меньше 15 секунд, при почти неизменной позиции — до 60 секунд. Это не плавная векторная карта. Старое изображение при потере связи помечается возрастом; метка на нём тоже может быть старой. За сеанс разрешено до 240 попыток API; продолжение — через сброс счётчика в меню. Лимит приложения не заменяет ограничения и условия Яндекса.

## Проверка и сборка исходников

Для сборки нужен Python 3, для тестов — Node.js. Зависимости npm не скачиваются. Совместимость синтаксиса и тестов проверялась именно на Node.js 8.16.2 Linux x86-64.

```sh
python3 tools/build.py
node tests/run.js
node tests/transport.js
node tests/ui.js
node tools/preview.js
```

Сборка создаёт `dist/aren_yandex@0.2.1.tgz`, `dist/catalog.json`, `dist/SHA256SUMS` и `dist/usb/mgu-repo/mgu-yandex-navigation/`. Архив не содержит BMW SDK. Формат результата воспроизводим при одинаковом исходном дереве, окружении каталога SOME/IP и версии Python/zlib.

Дополнительная проверка настоящим Store:

```sh
git clone https://github.com/robertnisipeanu/mgu-store.git ../mgu-store
git -C ../mgu-store checkout 83da03a115fb4073e791413066fd60da607e1932
node tests/store.js ../mgu-store
```

`tests/store.js` читает пакет, обнаруживает USB по тестовой таблице монтирования и строит список установки. Инсталлятор и службы автомобиля он не запускает.

`tools/verify.py --node node --store ../mgu-store` выполняет полный прогон и сохраняет его вывод. В `.github/workflows/verify.yml` подготовлена сборка артефактов GitHub Actions; в GitHub она ещё не запускалась и сама не публикует релиз. `python3 tools/bundle.py` упаковывает уже проверенный пакет и соответствующие исходники в поставочный ZIP.

Отчёт: [TEST_REPORT.md](docs/TEST_REPORT.md). Архитектура и источники: [ARCHITECTURE.md](docs/ARCHITECTURE.md). Кадр настоящего кода отрисовки без подключённого автомобиля: [preview-unconfigured.png](docs/preview-unconfigured.png).

## GitHub и дальнейшая установка из сети

В корне есть `mgu-repo.json`: исходники подготовлены для чтения MGU Store из репозитория. Готовые `catalog.json` и `.tgz` можно также опубликовать вместе как каталог релиза. Сетевой источник для MGU Store опубликован в `arenaren999/mgu-yandex-navigation`. В меню Store можно выбрать GitHub-источник и ветку `main`, чтобы собрать исходники на головном устройстве, либо добавить HTTPS-каталог `https://raw.githubusercontent.com/arenaren999/mgu-yandex-navigation/main/catalog.json`, чтобы установить готовый OAP-пакет `aren_yandex@0.2.1.tgz`. Испытание на автомобиле не выполнено.

Исходники продолжают прежний проект 0.1, но HTML-прототип заменён исполняемым OAP-приложением. Предыдущая записка сохранена в `docs/PROTOTYPE-0.1.md`. Доработки после испытания должны получать новую версию пакета.
