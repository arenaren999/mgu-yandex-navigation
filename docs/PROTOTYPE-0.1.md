# MGU Яндекс — прототип 0.1

Цель: автономная карта и построение маршрута на головном устройстве BMW MGU, **без CarPlay / Android Auto**.

## Что готово
- Экран карты, адрес назначения, маршрут с учетом пробок (если доступно в используемом API/тарифе), кнопка GPS.
- Веб-прототип для проверки на компьютере и в браузере MGU.
- Не использует телефон как источник изображения.

## Что НЕ готово
- Не является устанавливаемым `.mgu`-приложением; пока не интегрирован с BMW OAP/RHMI.
- GPS берется из браузера; браузер MGU может не иметь Geolocation API. Нужен адаптер к штатному GPS MGU.
- Нет голосовых подсказок, пошаговой навигации, управления контроллером iDrive, HUD и кластера.
- Требуется ключ Яндекс Карт JavaScript API и проверка его лицензии, разрешенных доменов и условий использования. Некоторые функции маршрутов/пробок могут быть ограничены тарифом.
- Не тестировалось на BMW X6 G06 2021 I_21w12.2-1-4.

## Как запустить на ПК
1. Получите ключ JavaScript API Яндекс Карт на официальном сайте разработчика.
2. Вставьте его в `config.js` (не публикуйте файл с ключом).
3. Запустите `python3 -m http.server 8000` в этой папке.
4. Откройте `http://localhost:8000` в браузере. Геолокация обычно требует HTTPS или localhost.

3. Подключить штатные координаты автомобиля только через разрешенный read-only интерфейс, если доступен.
4. Проверить доступность Яндекс API из сети MGU, не вмешиваясь в штатную навигацию и автомобильные системы.
5. Собрать отдельный установочный пакет с резервной копией и откатом; тестировать на стоянке.

**Важно:** это исследовательский прототип, не готовая автомобильная навигационная система. Не использовать для управления автомобилем во время движения.
