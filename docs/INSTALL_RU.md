# Установка через MGU Store и первая проверка

## Состав USB

В поставочном ZIP есть папка `USB`. Скопируйте **её содержимое** в корень уже используемой с BMW флешки, не стирая другие файлы. Для этой задачи форматировать носитель не требуется.

| Путь от корня флешки | Назначение |
|---|---|
| `mgu-repo/mgu-yandex-navigation/catalog.json` | Каталог приложений Store |
| `mgu-repo/mgu-yandex-navigation/aren_yandex@0.2.2.tgz` | Готовое приложение |

`SOURCE`, инструкции, исходный ZIP и отчёты на флешку переносить необязательно. Файл `.tgz` оставьте архивом. Не размещайте вторую копию того же пакета в `oap/`: один источник достаточен.

## Действия в BMW

1. На стоящем автомобиле подключите флешку и откройте Store. Используйте привычный для работы приложений режим питания, при котором автомобиль не уходит в сон посреди установки.
2. Откройте **USB** и выберите **MGU Yandex Navigation · Experimental 0.2.2**. В другой версии интерфейса откройте **Sources / Источники**, источник с названием флешки и путём `mgu-repo/mgu-yandex-navigation`.
3. Убедитесь, что ID приложения — `aren_yandex`, HMI — ID7. Нажмите **Install / Установить**.
4. Если Store требует обновления, обновите `mgu-deploy` как минимум до 0.8.27, `mgu-uplink` как минимум до 0.7.13 и повторите установку. Зависимости не вложены в USB-пакет: Store получает их из своих источников. Обновление системных компонентов и их совместимость с машиной этим проектом не тестировались.
5. Во время установки Store может перезапустить OAP-приложения — это поведение его установщика. Дождитесь статуса установленного приложения.
6. Найдите **MGU Yandex Navigation** в приложениях BMW. Если карточка не появилась, сначала проверьте результат в Installed / Установленные; не меняйте прошивку ради этой проверки.

Если такая же версия уже была установлена из другого источника, Store может отказаться от конфликтующего ID. Сообщение Store нужно сохранить для разбора; устанавливать одновременно две копии приложения не требуется.

## Подключение Яндекса

Нужен собственный доступ в [кабинет разработчика Яндекса](https://developer.tech.yandex.ru/). Ввод производится локально на MGU штатной клавиатурой: меню приложения → нужный ключ → OK. Не присылайте секретные ключи в чат и не публикуйте их в GitHub.

| Поле приложения | Сервис | Что даёт |
|---|---|---|
| Карта / Ключ Static API | Static API | Изображение карты |
| Поиск / Ключ Геокодера | HTTP API Геокодера | Адрес → координаты |
| Маршруты / Ключ маршрутов | API Получение деталей маршрута | Геометрия, расстояние и время автомобильного маршрута |

Ключ JavaScript API из прежнего браузерного прототипа нельзя считать подходящим автоматически. Проверяйте доступ именно к нужному сервису. Условия доступа, квоты и ограничения ключа определяются кабинетом Яндекса. Код обращается по HTTPS напрямую с MGU, а не со страницы в браузере, поэтому настройки, рассчитанные только на HTTP Referer сайта, могут не подходить. Не снимайте ограничения с ключей других проектов ради эксперимента; используйте выделенный доступ для этого приложения.

Для первого испытания достаточно Static API: в **Найти** можно ввести координаты в формате `55.751,37.618`, выбрать результат и проверить загрузку карты. Это пример явно введённой точки, а не подстановка вашей позиции. Для адресного поиска и маршрута нужны соответствующие дополнительные сервисы.

Ключи лежат в файле `yandex-keys.json` в каталоге данных приложения, режим файла 0600. Это защита правами файловой системы, не шифрование. Меню **Удалить все ключи Яндекса** требует отдельного подтверждения. Статусы и журналы приложения не содержат полного URL запроса или самого ключа.

## Последовательность испытаний

| Проверка | Ожидаемый результат | Если не получилось |
|---|---|---|
| Запуск без ключей | Русский экран ожидания, работает Меню и выход | Сохранить сообщение Store/журнала запуска |
| Клавиатура | Открывается штатный ввод, Cancel возвращает в приложение | Отметить версию ПО и сообщение об ошибке |
| Карта заданной точки со Static API | Настоящее изображение Яндекса, видны его подписи и атрибуция | Проверить интернет MGU, ключ, HTTP/TLS-ошибку |
| Штатный GPS под открытым небом | Позиция соответствует месту автомобиля | Важны реальная доступность Positioning на этой прошивке и свежесть данных |
| Поиск адреса | Список адресов, выбранная точка на карте | Проверить доступ к Геокодеру |
| Маршрут | Линия, расстояние, время; начало соответствует GPS | Проверить доступ к API маршрута; при отсутствии GPS допустим явный ручной старт |
| Потеря сети/GPS | Понятный статус, интерфейс остаётся отзывчивым | Записать время и текст ошибки без ключей |
| HOME, BACK, штатная камера, возвращение | Системные экраны имеют приоритет, приложение возобновляется | При зависании прекратить испытание и удалить приложение через Store |
| Сон и повторный запуск MGU | Ключи сохранены, автоматический поиск прежнего маршрута не выполняется | Сохранить журнал без личных координат и ключей |

После стояночной проверки работу с движущимся GPS оценивает пассажир. До подтверждения на машине это экспериментальный просмотр карты; для реальной поездки используйте уже проверенную навигацию. При потере GPS прежняя метка может остаться внутри старого изображения — проверяйте статус GPS и возраст карты.

## Сообщения и действия

| Сообщение/ситуация | Значение и действие |
|---|---|
| Источник не появился | Проверить точный путь двух файлов, распаковку ZIP и доступность флешки для BMW; открыть Store повторно |
| Not installable / Недоступно для установки | Прочитать конкретную причину: HMI, зависимость или конфликт ID; не игнорировать её |
| Ошибка SDK / donor / SOME-IP | Нужна проверка установщиком на конкретной прошивке; пакет не включает чужой BMW SDK |
| GPS недоступен | Не подставляется вымышленная позиция; временно можно выбрать точку или явно задать начало вручную |
| API: проверьте ключ / 401 / 403 | Проверить сервис, активацию и ограничения ключа |
| TLS | Проверить дату MGU и состояние сертификатов/сети; проверка сертификата в приложении остаётся включённой |
| Нет соединения с Яндексом | Проверить интернет именно у MGU через uplink |
| Лимит Яндекса / 429 | Повторная попытка не ранее чем через минуту; проверить квоту сервиса |
| Лимит запросов за сеанс | 240 попыток израсходованы; продолжение вручную через меню |
| Карта не поддерживается | PNG не соответствует допустимому формату; нужен разбор ответа без публикации ключей |

## Удаление

При необходимости сначала удалите ключи в меню приложения. Затем Store → Installed / Установленные → MGU Yandex Navigation → Remove / Удалить. Если предлагается удалить связанные инструменты, для удаления только этого приложения выбирайте соответствующий вариант, сохраняя общие компоненты Store. Сам Store и другие источники ради этого удалять не нужно.

Удаление, перезапуск и возврат приложения на этом BMW пока не испытаны. Не считайте наличие пункта Remove подтверждением проверки восстановления на автомобиле.
