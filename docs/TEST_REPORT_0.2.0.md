Проверка завершена 22 ноября 2026 года, 21:52 МСК. Среда — Linux x86-64, настоящий Node.js **v8.16.2**, Python 3.12. BMW не подключён. Сырые результаты сохранены в [test-results/report.json](test-results/report.json) и отдельных `.txt` рядом.

Сценарии основной логики включают отказ от невалидной/устаревшей GPS-позиции, раздельную свежесть скорости, отсутствие сетевого запроса без точки, отмену устаревших ответов маршрута/карты/поиска, отсутствие новых запросов на скрытом экране, ограничение частоты и 429, ручное начало, права ключевого файла 0600, декодирование PNG и отказ от распаковки чрезмерного размера.

## Сеть: проверка не прошла

Три обращения **без ключей** из Node 8 к Static API, Геокодеру и Router завершились `NETWORK`; TLS не был установлен. Отдельная диагностика прямого подключения показала `EAI_AGAIN` (DNS в среде разработки; в окружении настроен прокси). Это ограничение данного стенда, а не полученный ответ Яндекса об ошибке ключа.

Успешных запросов карты, геокодирования или маршрута с действующим ключом **не было**. Проверки с фикстурами подтверждают логику обработки, но не доступ конкретного API-аккаунта, живой формат изображения или TLS на MGU. Проверка сертификата не отключалась; обходной небезопасный прокси не добавлялся.

## Точный установочный артефакт

```text
aren_yandex@0.2.0.tgz
bytes: 1329984
sha256: 3d828184fde40944fc102866fcdf7b36607e74d433c6cb9a7c283027a1c4c455
```

Внешний ZIP содержит этот файл, каталог USB, исходники и результаты проверок. SHA-256 выше относится именно к `.tgz`, а не к ZIP. Код ревизии Store: `83da03a115fb4073e791413066fd60da607e1932`.

Команда полного прогона:

```sh
python3 tools/verify.py --node /path/to/node-v8.16.2/bin/node --store /path/to/mgu-store --network
```

Параметр `--network` необязателен: он запускает только проверку соединения без ключей, с отдельными результатами по сервисам. Выполнение этого скрипта не запускает установщик и не связывается с автомобилем.

## Что требует целевого автомобиля

1. Принятие пакета реальным Store и подготовка donor SDK/SOME-IP на I_21w12.2-1-4.
2. Запуск, регистрация карточки, работа iDrive, штатной клавиатуры и кнопки BACK.
3. Реальная позиция `Positioning.currentLocation`, её обновление и поведение при потере спутников.
4. Интернет MGU и TLS с действующими ключами Яндекса; успешная карта, адрес и маршрут.
5. Приоритет штатной камеры/экранов, скрытие приложения, сон, пробуждение, удаление.
6. Плавность и читаемость карты, нагрузка и расход трафика при движении.

Итоговый статус: **пакет для пробной установки через Store подготовлен и структурно проверен; совместимость и практическая работоспособность в BMW не подтверждены**. Голосовая навигация, повороты, HUD/приборка и автоматическое перестроение в 0.2.0 не реализованы.
